Your SkyNetworks admin.html

This is the staff admin page, ready to save as a file named admin.html.

Option 1: save the file

Option 2: copy the code

If saving doesn’t work, copy the code and paste it into a new file on GitHub.

Then on GitHub

  1. Open your repository and tap Add file.
  2. Option 1: tap Upload files and pick the saved file. Option 2: tap Create new file, type admin.html as the name, paste the code, then commit.
  3. The saved file should be about 13 KB. If it is 3 MB or more, it is the wrong file.
